# Экраны состояния и загрузка больших архивов — 25 октября 2026

Второй этап по запросу пользователя: русские экраны ошибок/загрузки, облегчённые
данные страниц и постраничный архив. Почта, рабочая БД, публикация и Git-коммиты
не затрагивались. Текущие пользовательские изменения сохранены.

## Реализация

- Корневые и семейные `error.tsx`/`loading.tsx` используют общие компоненты и
  изолированный CSS module. Ошибка фокусирует заголовок, предлагает повтор и
  список семей. Сообщение/stack/digest исходной ошибки не отображаются.
- `family-workspace-reader.ts` выбирает краткие данные всех активных людей и
  одну фотографию каждого, без биографий, заметок, историй и legacy memory.
  Полная карточка читается только для явно выбранного активного человека, с
  фильтрами ID семьи и статуса. Обзор не загружает произвольную первую карточку.
- Редактору дополнительно передаются только архивные участники/источники связей
  выбранного человека. Точные ID/version/origin связей сохраняются.
- `detailsLoaded: false` блокирует персональные изменения до полной загрузки.
  Исчезновение выбранного человека между запросами вызывает восстанавливаемую
  ошибку вместо бесконечного индикатора.
- Новые readers архива/журнала не используют полный граф. Архив читает 24+1
  запись диапазонами ID и предлагает предыдущую/следующую страницу. Опустевшая
  страница после восстановления отделена от пустого архива. Журнал выбирает
  только заголовок и до 100 событий, как и прежде.
- На страницах людей/фото/воспоминаний не вычисляются геометрия и родство скрытого
  дерева. Порядок React hooks и существующие режимы дерева сохранены.
- Полные запросы и проверки графа внутри транзакций изменений не сокращались.

## Миграция и ограничения

Подготовлены schema-индекс `(familyId, isArchived, id)` и миграция
`20261025000000_archive_pagination_index`. Она не применялась к рабочей БД.
До её отдельного применения/проверки ускорение SQL не подтверждено.

PostgreSQL integration/migration/EXPLAIN не запускались, покрытие не измерялось.
Все активные вершины и рёбра по-прежнему нужны для полного дерева; данные большого
выбранного медиаархива/историй пока загружаются полностью, без скрытого усечения.
