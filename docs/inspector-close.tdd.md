# Крестик в карточке выбранного человека

Дата: 14 сентября 2026. Требование: добавить X в правый верхний угол карточки для выхода из выбранного человека.

- Реализация: нативная кнопка 44 × 44 px с доступным названием «Закрыть карточку человека», декоративным SVG и видимым фокусом. Используется существующий `clearSelection`; верхняя кнопка снятия выбора сохранена.
- RED: новый SSR-тест падал с `0 !== 1`; остальные 182 теста проходили.
- GREEN: `npm test` — 183/183, без пропусков; `npm run lint` — без предупреждений и ошибок; `npm run build` — успешно, включая проверку типов.
- SSR проверяет наличие кнопки внутри панели только при действительном выборе, как для редактора, так и для пользователя без права редактирования.
- Браузер: после пересборки и перезапуска проверен публичный `/demo` с вымышленными данными. Крестик виден справа в заголовке, размер нажатия 44 × 44 px. Клик закрывает панель, снимает выделение и возвращает фокус в поиск.
- Клавиатура: выбран другой человек, включено «Скрыть остальных» (6 из 8); Enter на крестике возвращает все 8 человек, сбрасывает checkbox и выбранную перспективу, убирает личную панель.
- ECC `frontend-a11y` определил семантику кнопки, размер цели и фокус; `tdd-workflow` — последовательность RED/GREEN. Независимое read-only ревью не выявило замечаний к обработчику и адаптивной сетке.

Данные семьи, база, разрешения и круговая геометрия не изменялись. Процент покрытия не измерялся. Основной сервер оставлен работающим на 127.0.0.1:3000.
