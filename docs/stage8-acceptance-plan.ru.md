## Порядок прогона

1. Дождаться pg_isready нового контейнера. Задать TEST_DATABASE_URL только для
   текущего процесса и RODOVO_CI_DATABASE=disposable. DATABASE_URL переопределить
   на недоступный тестовый loopback URL, отличный от TEST_DATABASE_URL.
2. Запустить `npm run ci:database`: миграции, status, schema diff, история и
   checksum. При ошибке исследовать причину, не применять reset/migrate resolve
   и не редактировать ранее применённые SQL для сокрытия расхождения.
3. Запустить `npm run test:integration`: 12 файлов интеграционных тестов по
   аккаунтам, приглашениям, участникам, созданию семей, людям/ID, родственным
   связям, историям/миграции контента и квотам медиа. Точное число тестов и
   результаты записать из вывода, не подменять результат unit-тестами.
4. Исправления подкрепить воспроизводящей регрессией и независимым review;
   повторить затронутые проверки и итоговый интеграционный набор.
5. Записать версии, результаты и ограничения без URL/паролей/семейных данных.
   Остановить и удалить только созданный для этапа контейнер после завершения;
   его tmpfs и синтетические записи одноразовые.

## Критерии завершения

Все миграции применены на новой БД, история/checksum/schema совпадают, все
интеграционные тесты проходят без пропусков, найденные дефекты исправлены и
проверены. Отдельно отметить: этот прогон не подтверждает обновление реальной
старой базы, доставку почты/оповещений, полный backup restore, браузерную матрицу
или rollback приложения. Production deploy и применение рабочих миграций не
входят в этот этап.

Независимый database review уточнил границы: тест content migration повторяет
один UPDATE классификации на новой схеме с 8 вариантами данных. Переход старой
заполненной схемы целиком, legacyAccount, старые сессии, default ready для старых
медиа и manual для связей этим прогоном не доказаны. Конкурентные тесты используют
реальные транзакции и барьеры, но не являются нагрузочным/многопроцессным тестом.
Медиа-проверки касаются БД и квот; файловая запись и сбой процесса между файлом
и commit здесь не проверяются.
