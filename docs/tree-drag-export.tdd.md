# Перемещение кругов и экспорт семейного дерева

Дата: 14 сентября 2026. Сценарии получены из запроса пользователя: двигать отдельных людей и экспортировать красивую схему в PNG/PDF, в том числе в виде дерева.

Последующее уточнение структуры и выбора человека описано в `rooted-tree-export.tdd.md`: для «Живого дерева» оно заменяет нижеописанные направление поколений и правило экспорта только видимых людей. Drag и круговой экспорт сохраняют прежнее поведение.

## Поведение

- Перетаскивание круга двигает только человека и пересчитывает его реальные связи; пустой фон перемещает камеру. Короткое нажатие по-прежнему выбирает человека.
- Shift + стрелки двигает круг на 12 единиц схемы. Escape / pointercancel отменяет текущий жест. Масштаб учитывается в координатах, круги ограничены границами полотна.
- Ручные позиции хранятся только в памяти страницы, отдельно для семьи, выбранного человека и режима видимости. «Сбросить расположение» восстанавливает исходный круг. Никаких записей в базу.
- «Экспорт PNG / PDF» открывает нативный диалог с предпросмотром. «Живое дерево» строит отдельную композицию по поколениям с декоративными ветвями; «Круговая схема» сохраняет ручные позиции.
- В экспорт включены только видимые люди и их записанные связи, имена и даты. Фото, биографии, заметки и рассказы не включены. Всё создаётся локально в браузере.
- PNG до 2×, ограничение 16 МП / 8192 px. PDF содержит изображение на одном листе A3 с подходящей ориентацией и полями 10 мм. Это растровый PDF, не документ с выделяемым текстом.

## Браузер и файлы

Проверка через Codex CUA, без отдельного Playwright/CDP, на изолированном loopback fixture с вымышленной семьёй (8 людей / 11 связей):

- Drag выбранного круга: +92 / -69 px при 100%; только его координаты изменились, камера и остальные узлы неизменны.
- Drag фона: камера -30 / -30 px, позиции узлов неизменны. Shift + ArrowRight: ещё +12 единиц только выбранному кругу.
- Escape закрывает экспорт, сохраняет выбранного человека и ручное положение, возвращает фокус на кнопку экспорта.
- Сброс возвращает точные исходные координаты. Выбор отца + checkbox ограничивает экспорт до 5 из 8 человек.
- Оба оформления визуально проверены; в круговом предпросмотре отражены ручные позиции.
- Скачаны настоящие PNG **2680 × 2228** и PDF. PDF независимо открыт через pypdf/Poppler: 1 лист, A3 landscape, 1190.55 × 841.89 pt, JPEG 2680 × 2228. PDF отрендерен обратно в PNG и просмотрен; имена, даты, дерево, связи, рамка и легенда без обрезки. Исходный PNG также просмотрен.
- CUA-событие download не сработало для Blob-загрузки, но фактические файлы найдены в Downloads, открыты и проверены. Это ограничение тестового события, не отказ экспорта.
- Мобильная ширина 375px: диалог 339px, содержимое 322px, горизонтального переполнения нет; кнопки загрузки доступны в прокручиваемом окне. Временный viewport сброшен.
- После production-сборки `/demo` обновлён: экспорт/предпросмотр работают, ошибок консоли не обнаружено. Основной сервер оставлен на 127.0.0.1:3000; временные fixture-вкладка и сервер закрыты.

Проверочные изображения и PDF содержат исключительно вымышленные данные; хранятся в `tmp/pdfs/`.

## ECC, источники и ограничения

ECC `tdd-workflow` использован для RED/GREEN, `frontend-a11y` — для управления клавиатурой, нативного диалога и возврата фокуса. Независимое ECC TypeScript/React ревью drag и export lifecycle не выявило actionable-регрессий. Навык `pdf` определил независимый render-and-inspect PDF; marker операции успешно запущен перед созданием проверочного PDF.

Сверены первичные браузерные справочники: [Pointer capture](https://developer.mozilla.org/en-US/docs/Web/API/Element/setPointerCapture), [Canvas toBlob](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/toBlob), [showModal](https://developer.mozilla.org/en-US/docs/Web/API/HTMLDialogElement/showModal).

Процент покрытия не измерялся. При ручной расстановке можно наложить круги друг на друга; автопредотвращение коллизий не добавлялось. Очень большая семья на одном A3 будет мелкой; многостраничная печать не входит в изменение. Декоративные ветви не создают родство, его показывают только реальные линии. Конфигурация Neon, семейные данные, права доступа, production CSP и зависимости не менялись. Commit/push/deploy не выполнялись.
